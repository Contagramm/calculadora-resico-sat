✅ INSTALACIÓN COMPLETADA

Las dependencias ya están instaladas. Solo necesitas iniciar la app.

═══════════════════════════════════════════════════════════════
  PASO 1: INICIAR LA APLICACIÓN
═══════════════════════════════════════════════════════════════

1. Abre una terminal en esta carpeta
2. Ejecuta: npm run dev
3. Abre tu navegador en: http://localhost:5173

═══════════════════════════════════════════════════════════════
  PASO 2: USAR LA APLICACIÓN
═══════════════════════════════════════════════════════════════

SUBIR FACTURAS EMITIDAS (Ingresos):
  1. Selecciona "Facturas Emitidas (Ingresos)"
  2. Arrastra tus PDFs o haz clic para seleccionar
  3. Espera a que se procesen

SUBIR FACTURAS RECIBIDAS (Gastos):
  1. Selecciona "Facturas Recibidas (Gastos)"
  2. Arrastra tus PDFs o haz clic para seleccionar
  3. Espera a que se procesen

═══════════════════════════════════════════════════════════════
  PASO 3: REVISAR Y EXPORTAR
═══════════════════════════════════════════════════════════════

- Revisa la tabla mensual con todos los cálculos
- Haz clic en cualquier mes para ver detalles
- Exporta a CSV o Excel cuando estés listo

   → Ejecuta: npm install
   → Luego: npm run dev

❌ PDF no se lee bien:
   → Verifica que sea PDF con texto (no imagen)
   → Asegúrate de que tenga campos como "Subtotal", "IVA"

❌ Cálculos incorrectos:
   → Verifica que las facturas estén bien clasificadas
   → Revisa los datos extraídos en la lista de facturas
